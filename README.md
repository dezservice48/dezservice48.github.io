# Сайт «Дез Сервис Липецк»

Страницы: главная (index.html), klopy/, tarakany/, gryzuny/, biznes/, politika.html.
Общие файлы: favicon.svg, apple-touch-icon.png, og.png, robots.txt, sitemap.xml.

Загружайте на GitHub Pages всю папку целиком, с подпапками.

## Перед публикацией замените во ВСЕХ файлах (поиск и замена по папке)
- `dezservice48.github.io` → адрес сайта без https:// и без слеша на конце (все страницы, robots.txt, sitemap.xml)
- `YANDEX_CODE` → код из Яндекс Вебмастера, достаточно на главной (раскомментировать строку)
- Код Яндекс Метрики → перед `</body>` на каждой странице

Удобно делать замену в VS Code: Ctrl+Shift+H — замена сразу во всех файлах папки.
